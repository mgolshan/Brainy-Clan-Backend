## Devenez partenaire de Brainy Clan

Pour les parents et les créateurs qui partagent notre mission : que les enfants utilisent les écrans
pour apprendre et grandir plutôt que pour perdre leur temps. Recommandez Brainy Clan à d'autres
parents avec votre propre code et touchez une commission sur les forfaits payés.

## Brainy Clan en bref

Une application d'apprentissage en famille. Voici ce que vous pouvez dire : chaque point est vrai
aujourd'hui.

- Quiz, sudoku (de 4x4 à 9x9), sprint de maths, jeux de mots (anagrammes, lettre manquante, mots
  cachés) et jeux de cerveau (mémoire, suites, logimages, jeu des différences).
- Chacun joue à son niveau : les questions s'adaptent au groupe d'âge et à la difficulté de chaque
  joueur.
- Objectifs familiaux (quotidiens, hebdomadaires, mensuels) : faites la course ou faites équipe pour
  une récompense dans la vraie vie.
- Les enfants s'inscrivent avec un simple surnom : pas de courriel, pas de mot de passe, pas de vrai
  nom, pas de photo. Un parent donne son consentement pour chaque enfant.
- Aucune publicité pour les enfants, jamais. Pas de contact avec des inconnus : la seule discussion
  est celle de votre famille, et les parents peuvent la désactiver.
- Chaque question est révisée avant d'être publiée. En anglais et en français, sur iPhone, iPad et
  Android.

## Comment ça marche

1. **Postulez** — écrivez-nous avec vos chaînes et votre public. Nous vérifions que votre contenu
   s'adresse aux parents et respecte notre mission.
2. **Recevez votre code** — nous créons votre code personnel (par ex. `MAYA`) et votre lien
   `brainyclan.com/r/VOTRECODE`.
3. **Partagez avec #pub** — parlez de Brainy Clan aux parents, avec une divulgation claire dans
   chaque publication.
4. **Touchez une commission** — quand une famille utilise votre code et paie le forfait Famille,
   vous touchez une commission selon les conditions ci-dessous.

## Ce que votre public reçoit

Le forfait gratuit reste gratuit : n'importe qui peut essayer Brainy Clan sans payer. Votre code
relie la famille à vous. **Si votre code comprend une offre**, vos abonnés en profitent aussi :

- un code d'offre de l'App Store ou de Google Play, à utiliser lors de l'achat dans l'application;
- un rabais appliqué automatiquement quand ils s'abonnent sur brainyclan.com avec votre lien ou votre
  code (seulement quand le paiement sur le Web sera ouvert : le site n'affiche cette ligne qu'à ce
  moment).

Nous vous dirons quelle offre votre code comprend quand nous le créons. Ne promettez jamais un rabais
que nous n'avons pas confirmé.

## Commission et paiements

Conditions standard (votre entente écrite peut prévoir d'autres conditions; elle a priorité) :

| | |

| **25 %** des revenus nets | de chaque paiement d'une famille liée à votre code. Net = prix payé moins les taxes de vente et les frais de la boutique ou de Paddle. |

- Par PayPal, virement Interac (Canada) ou virement bancaire : paiement fait à la main par notre
  équipe.
- Votre relevé indique les montants par mois et par devise, jamais l'identité des familles.
- Vous êtes responsable de vos impôts, de vos taxes et de vos factures. Nous pouvons vous demander
  une facture ou vos renseignements fiscaux quand la loi l'exige.
- Ne nous envoyez jamais un numéro de carte, ni un numéro de compte complet par simple courriel :
  nous conviendrons d'un moyen sûr.

## Les règles

Brainy Clan est une application pour les familles. Ces règles protègent les enfants, vos abonnés et
vous.

**Toujours**

- Divulguez dans chaque publication, au début et de façon visible : « #pub », « #ad » ou
  « Partenariat rémunéré avec Brainy Clan », et dites-le à voix haute dans les vidéos (FTC, Bureau
  de la concurrence, Normes de la publicité).
- Adressez-vous aux parents et aux adultes.
- Utilisez seulement les affirmations de la section « Brainy Clan en bref » et de la trousse de
  marque.
- Restez fidèle à notre mission et à nos règles de contenu : positif, honnête, éducatif, sans prise
  de position politique, idéologique ou religieuse.
- Ne filmez un enfant qu'avec le consentement écrit de ses parents, et ne montrez jamais le nom ou le
  visage d'un enfant dans l'application.

**Jamais**

- Cibler ou interpeller des enfants, ou publier sur des chaînes destinées aux enfants.
- Faire des affirmations fausses, médicales ou sur les résultats scolaires (« meilleures notes
  garanties », « prouvé »), ni parler de certifications que nous n'avons pas.
- Envoyer du pourriel ou des messages non sollicités.
- Acheter des annonces sur le mot-clé « Brainy Clan » dans les moteurs de recherche.
- Publier de faux avis, payer ou récompenser des installations, faire du bourrage de témoins, ou
  utiliser votre propre code.

En cas de manquement, nous pouvons mettre fin au partenariat et retenir les commissions liées.

## Questions fréquentes

**Comment une famille m'est-elle attribuée ?** Une famille est liée au premier code de partenaire
qu'elle utilise : le premier code l'emporte. Le code doit être utilisé avant le premier paiement de
la famille; il est ensuite verrouillé. Nous n'utilisons ni témoins (cookies) ni pistage : une famille
n'est attribuée que si votre code est réellement utilisé.

**Et les achats dans l'App Store ou Google Play ?** Ils comptent quand le parent a entré votre code
dans l'application (à l'inscription ou sous « Vous avez un code ? ») avant de payer, ou quand il
utilise un code d'offre de boutique lié à votre code. Une fois le paiement sur le Web ouvert, votre
lien remplit aussi le code sur le formulaire d'abonnement du site.

**Quand suis-je payé ?** Une commission devient payable après la période de remboursement
(30 jours), puis elle est versée avec le paiement suivant (une fois par mois).

**Puis-je voir mes statistiques ?** Vous recevez un relevé mensuel par courriel (montants par mois
et par devise). Une page de statistiques est prévue. Nous ne partageons jamais l'identité des
familles.

**Que se passe-t-il en cas de remboursement ?** Si une famille est remboursée ou fait une
rétrofacturation, la commission de ce paiement est annulée et déduite de votre prochain paiement.

**Puis-je utiliser mon propre code ?** Non. Les auto-parrainages ne donnent pas droit à une
commission.
